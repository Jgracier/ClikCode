## Deviations found, and what was done

| Where | Deviation | Fix |
|---|---|---|
| Claude Code over claude-agent-acp | A background Agent's launching call completes at once; the row settled while the agent ran on (`async_task_*` / `task_*` frames were only a status phrase). | `events/background-agent-rows.ts` holds the row open from `task_started {is_backgrounded}` to `task_notification`, carrying `task_progress` tool uses/tokens and the end's duration; `acp-client.ts` asks claude-agent-acp for those raw frames (`ACP_SESSION_META`). `acp-vendor-signals.vitest.test.ts`. |
| Claude Code stream-json (and Amp/Qwen/Grok/Gemini, same parser) | Same: the launch result settled the row. | Same class in `events/adapters.ts` (`StreamState.agentRows`); a process that exits with a row held closes it stopped (`turn/vendor-cli-attempt.ts`). Recorded claude 2.1.281 stream in `background-agents.vitest.test.ts`. |
| Cursor over ACP | `subagent_spawned`/`subagent_state_update` were a status phrase; the spawning call settled at launch. | `acp-client.ts` holds the spawning call's row to the state update. Fake-ACP test only: CLAIMED. |
| Own agent, foreground sub-agent | A steer typed during the call waited for the call to end ("sending at the next pause"). | `turn-runtime.ts` `foregroundSteers`: the running sub-agent gets it at once, the main agent after the call. `subagent.vitest.test.ts` (fails without the change). |
| VS Code panel | The `send` setting was display-only. | `IdeChoice {kind:'send'}` -> `/send`, a Steer/Queue control in the permissions menu (`picker.tsx`, `bridge-choose-settings.ts`); same wording as the terminal (`SEND_MODE_DETAIL`). |
| Tests | `skills.vitest.test.ts` depended on the home directory being a repository; `prompter-live-rows` expected the removed "click" hint. | Hermetic temp base; test now asserts the one animated agent row with its call under it. |
| pty scenarios | `other-conversation-and-back-mid-turn` and `joined-turn-scroll-moves-whole-screen`: stale scenarios (twelve/thirty calls are now one "Ran N commands" row, so the rows they counted no longer exist). The other four baseline failures passed on this build (not reproduced: flaky under load or fixed since). | Scenarios corrected to the folded row / answer-paragraph fixture; not product bugs. |
