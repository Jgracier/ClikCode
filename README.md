# ClikCode

ClikCode is the standalone, local-first coding-agent harness. It normalizes
provider selection, sessions, models, permissions, reasoning controls, MCP,
skills, plugins, agents, and other provider-native capabilities while leaving
authentication and interactive managers in each vendor's own CLI.

Build with `pnpm --filter @clikdeploy/clikcode build` and run
`apps/clikcode/dist/index.js`.
